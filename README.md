# FocusFlow — Study Planner

A responsive browser-based study planner built with HTML, CSS, and JavaScript.

## Run it

Open `index.html` in any modern web browser. No installation or server is required.

## Portfolio features

- Add tasks with a subject, deadline, estimate, and importance level
- Automatic priority score for the next best task to focus on
- Mark tasks complete, delete tasks, and clear completed work
- Weekly study dashboard and completion metrics
- Responsive layout for desktop and mobile
- Persistent browser storage using `localStorage`
